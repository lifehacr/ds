# Domain Selling Platform

A simple platform to sell domains with payment integration.

## Features
- Browse available domains.
- Purchase domains with Stripe.

## Setup Instructions

### Backend
1. Navigate to the backend folder.
2. Run `npm install`.
3. Replace `your-stripe-secret-key` in `server.js` with your Stripe Secret Key.
4. Start the server: `npm start`.

### Frontend
1. Navigate to the frontend folder.
2. Run `npm install`.
3. Replace `your-stripe-publishable-key` in `App.js` with your Stripe Publishable Key.
4. Start the frontend: `npm start`.

### Netlify Deployment
1. Push the frontend code to your GitHub repository.
2. Connect your repository to Netlify.
3. Deploy the frontend.
